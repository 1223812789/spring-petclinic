# Composite Greeting Action

This local composite action greets a user, generates a random number, exposes it as the `random-number` output, and calls a local `goodbye.sh` script.

## Inputs

| Name | Required | Default | Description |
| --- | --- | --- | --- |
| `who-to-greet` | Yes | - | The user name to greet |

## Outputs

| Name | Description |
| --- | --- |
| `random-number` | A random integer generated by the action |

## Example

```yaml
steps:
  - name: Checkout repository
    uses: actions/checkout@v4

  - name: Run composite greeting action
    id: composite
    uses: ./actions/composite-greeting
    with:
      who-to-greet: Alice

  - name: Show generated value
    run: echo "Random number: ${{ steps.composite.outputs.random-number }}"
```

## Behavior

The action prints a greeting, generates a random number, exposes it through the output, and invokes `goodbye.sh` from the action folder.
